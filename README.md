# Childrenite Chasm

Full-colour Python 3 neon wall-kick climber for ElbowOS.

A lime/violet chasm scrolls past a glowing climber. Autoplay (and A / D or arrow keys) threads the gap, kicks off the walls, and snags amber gems. Magenta spikes break the combo.

Not a ROM, not an emulator, no trademarked characters.

## Play

```bash
pip install -r requirements.txt
python3 childrenite_chasm.py --play
```

## Record a 9:16 reel

```bash
python3 childrenite_chasm.py --record
```

Writes a 15-second 1080x1920 h264 MP4 (dummy SDL video driver if no display).
